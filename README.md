# MDVHeadOres 1.0.7

Actualización pequeña sobre 1.0.6.

## Nuevo comando admin

- `/mdvheadores queue`
- Alias internos: `/mdvheadores status`, `/mdvheadores cola`, `/mdvheadores estado`

Muestra:
- chunks pendientes en cola;
- chunks listos para procesar;
- límite máximo de cola;
- ritmo del throttle;
- procesados/encolados/omitidos por cola llena;
- tiempo aproximado para vaciar cola;
- conteo por mundo.

Permiso: `mdvheadores.admin`.
